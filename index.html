OWL'S QUICK GUIDE

FIVE RULES, ONE PAGE

A little map for the night

These are the simplified rules used by Disk Duel's lessons and simulator.

USEFUL TERMS

Arrival time (AT)

When a process becomes ready to use the CPU.

Burst time (BT)

How much CPU time the process needs in total.

Completion time (CT)

The time when the process has finished.

Turnaround (TAT)

CT − AT: time from arrival until finish.

Waiting time (WT)

TAT − BT: time spent ready but not running.

Preemption

Pausing one running process so another can use the CPU.
